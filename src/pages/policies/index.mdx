These rules apply across all four assessments, so each assessment page can
stay focused on its own brief rather than repeating them.

## Late work

Work submitted after its due time loses 5% of the available marks for each
calendar day late, up to five days, after which it is not accepted without an
extension. Because [the Pattern Diary](/assessments/pattern-diary/) is checked
for the consistency of entries made close to the moment described, a late
diary submission is judged on the entries that exist rather than penalised
twice — the lateness penalty above still applies, but markers do not also mark
down entries for being late once they've arrived.

## Extensions

Ask for an extension before the deadline, not after it, except where the
reason for asking only became clear afterwards (illness, an emergency). A
short, specific request — what happened, and how many days are needed — is
enough; no documentation is required for extensions of three days or fewer.
[Workshops](/sessions/) are the easiest place to raise a looming deadline
early, since the teaching team running that week's workshop can usually agree
an extension on the spot.

## Academic integrity

Every assessment in this course asks for an account of your own noticing, your
own reasoning, or your own designed system — not a general essay that could
have been written by anyone about anyone's coincidence. Using an AI tool to
help draft, edit or check your own account is permitted and should be named in
a line at the end of the submission saying what the tool was asked to do; using
one to invent the underlying moment, dream, reading or diary entry you then
write about is not, because at that point the "account" has nothing left to be
honest about. If you are unsure whether a particular use crosses that line,
ask before submitting rather than after.

## Getting help

The fastest path for a question about a specific assessment is the workshop
tied to it — see each assessment's own page for which one. Outside workshop
hours, [the people page](/people/) lists both members of the teaching team and
how to reach them. There is no question about this course too basic to ask;
a course built around "is this pattern meaningful or not" gets that question
asked about itself constantly, and answering it plainly is part of the job.
